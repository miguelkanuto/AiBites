# AGENTS.md

Projeto `rag-in-action`: chat com Chainlit + LlamaIndex usando OpenRouter.

## Comandos
- Instalar: `uv sync`
- Rodar: `make run` (`uv run chainlit run src/main.py -w`)

## Convenções
- Código em `src/main.py`; Python 3.13 e gerenciador `uv`.
- Variáveis de ambiente em `.env` (modelo em `.env.example`); nunca commitar `.env`.
- Respostas e prompts em português do Brasil.
